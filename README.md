# Task Manager Web Application

A full-stack Task Manager application developed using the MERN stack (MongoDB, Express.js, React.js, Node.js). This application helps users efficiently manage daily tasks with features like adding, updating, completing, and deleting tasks.

---

## Features

- Add new tasks
- Update task status
- Delete tasks
- Mark tasks as completed
- Responsive user interface
- MongoDB database integration
- REST API communication

---

## Tech Stack

### Frontend
- React.js
- CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## Installation

### Clone Repository

```bash
git clone https://github.com/DHARUNYADEVI/Task-Manager.git
```

---

## Backend Setup

```bash
cd backend
npm install
node server.js
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm start
```

---

## Environment Variables

Create a `.env` file inside the frontend folder and add:

```env
REACT_APP_API_URL=http://localhost:5000
```
